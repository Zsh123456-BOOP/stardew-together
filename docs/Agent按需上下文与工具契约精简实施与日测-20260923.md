# 按需上下文与工具契约精简：实施与日测

日期：2026-09-23。状态：实现及离线验证完成，隔离原生预检和同档一天对照待运行。本文件随日测补齐实际结果。

## 已实现

- 成就按已核实的同指标系列取下一档；收入、鱼种、总钓获、不同好感阈值分别处理。晨间/进度变化供给短候选，已选成就常驻；`progress.catalog` 支持 summary/detail、series、next_only 与分页，完整条件仍可按 ID 查询。普通决策取消全目录检查。
- 当前建设目标保留必要配方材料；不随手附带未选配方、建筑及高阶成就。候选与目标通过 `prerequisites.facts` 共用材料事实；未选采购阶段隐藏完整种子报价表，相关店面窗口保留，详情可读。库存、农务负担、当前任务、失败及承诺仍保留。
- 采购原生 effect 增加品质，日记用同一 command_id 内的品质/数量/费用验证关联。只归并准确匹配的衍生入包/扣款，保存支持证据；两笔交易仍累计两笔，不匹配的变化继续保留。默认日记只提供当天紧凑事实，原始记录归档。
- 请求冻结 ToolSpec，发送与整批 Decode（含计划内动作）共用 Schema。work.run 的参数和说明改为结构化配置，Catalog 文本也从该配置生成；常用农務/资源/仓储可直接调用，钓鱼/矿洞/畜牧/伙伴生产按实际任务或 lookup 展开，活动任务保留配置。补全 stock_target、cleanup_id、additional、exact_quality、start_level、region、travel_budget、keep_gold 等原来藏在说明中的参数。保留开放扩展字段；已知但本轮未加载的参数、未加载 goal 及角色错配整批拒绝。
- context.read 可一次读 1–4 个 section。查询按规范化参数和新鲜内容版本归并，命中仍携带实际内容；先重读相关原生域，因此这个 memo 不承诺减少原生读操作或模型调用轮数。新增相同结果重复查询统计。
- 每次请求归档发送前冻结视图与字段内容版本、工具配置。报告记录请求模型、返回模型及 fingerprint（供应商未返回时保持缺失）；中文优先，未将小样本英文翻译当作成本收益。
- 启动器支持经核验的独立 XDG 配置/存档目录和加载已有 AgentLab 存档，记录实际保存路径；原存档和其他窗口不参与测试写入。
