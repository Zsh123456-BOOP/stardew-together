- `tools.lookup` 支持 7 个能力组及名称/用途查询。查询过的完整定义在 checkpoint 保留三轮（跨日过期），活跃任务跨天保留相关工具；所有描述直接取自注册表，未截断参数。定义可见不授予预算或原生解锁。
- `ContextBudget` 统一调用 `DecisionContext`：当前库存/排程替代旧快照；历史计划指向回读，终态事件保留 ID、参数、真实数量与失败原因；原始日志不改写。
- 去掉重复目标、回执信封、历史证据数组、已送达的排程历史；日志与 `query.read` 继续保存完整证据。失败记录补地点、任务参数与条件版本，不能把不同工作合并成全局禁止。
- 前置条件按活跃目标、当前机会与部分已知配方生成材料缺口，不再每轮展开无关的后期配方未发现说明。保留发展目录补读入口。
- 当前候选与活动队列受预算保护；预算紧张不能静默隐藏它们。新增请求中原始/投影字符数、工具清单与数量遥测，API 原始 input/output/cache token 继续记录。
- 对此前真实出现的完整 JSON 后 `</result>` 或 `"}` 尾缀做严格白名单恢复；不修改 JSON 内部、拒绝第二对象、截断 JSON、额外正文或无效动作 schema。
