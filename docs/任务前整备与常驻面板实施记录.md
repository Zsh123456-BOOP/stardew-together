## 2. 当前适配边界

TaskPreparation 已覆盖常规种植、浇水、清理、采料、鱼矿行程、制作/烹饪、简单机器投料收货和采购的整备声明。

不能把它说成所有技能都完整接通：

- 建造、部分交付和特殊玩法尚没有完整的材料需求声明；未知能力保守保留背包物品，不擅自卸货。
- 机器额外燃料和复杂交付仍保守保留其他物资。
- 当前选择一个能满足此行需求的授权箱子；尚未合并多个箱子的分散物资。
- 仓库候选在本地图按已有寻路长度计算，跨地图使用可达性检查及保守成本，不是完整跨图运输优化。
- 两容器模拟避免不可能的满箱交换，但可选入库子集采用有限筛选，未宣称全局最优。
- 普通未知掉落仍可能中途满包，不能保证每趟所有产物都能带回。
- 未新增出售、丢弃或背包升级权限；未修改原生容量、经验、金钱或进度。
- NativePlayerOnly 下小禾仍只陪同；没有提前开启伙伴劳动。
