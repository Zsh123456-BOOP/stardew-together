# 同行 · Together 0.1 本机验收

环境：macOS / Stardew Valley 1.6.15 / SMAPI 4.5.2 / Squad 固定提交 a9084ef / .NET 6。所有改变地图、生成怪物、重置作物、测试传送的操作仅在 **AgentLab** 专用存档内进行。正式产品不开放实验指令、不加载本地 HTTP 桥，不使用图像控制游戏。

## 已完成的产品闭环

玩家聊天或空闲事件 → DeepSeek Flash 结合人设、真实关系、心情与近期经历决策 → 结构化约定 → 同一个 Squad NPC 执行动作 → 真实效果回执 → 更新约定、精力、亲近感和共同经历。

新增游戏内 F8 面板，包括聊天、角色邀请/离队、人设编辑、主动提议开关、约定同意/拒绝/强制/停止/继续、快捷活动和共同经历页。使用异步 HTTP，不阻塞游戏主线程；正式运行全部在 C# Mod 内完成。

## 真实游戏证据

| 场景 | 结果 |
| --- | --- |
| 指定 NPC 挖矿、另一 NPC 更近 | 指定角色真实移动并完成目标；不是把另一角色的动作算给它 |
| 2 次浇水 → 2 次收获 | 4 次动作均有 `effect_by_actor=true`；完整约定才变成 fulfilled |
| 模型提出交换条件 | 钓鱼人设回应“两块可以，多了我可不干”，返回 2 次挖矿加休息的协商方案 |
| 明确拒绝 | 新版 C# 实际收到 refuse 决策，并保留原任务步骤；普通“同意”被阻止、未派工；显式强制可以进入执行 |
| 接受模型约定 | 实际完成 2 次挖矿和 20 秒休息，完成数为 3 |
| 独立钓鱼 | 在海边走到有效站位、执行 30 秒钓鱼；首轮 0 收获如实记录 |
| 钓鱼遇怪 | 观察到战斗状态，原钓鱼任务恢复次数为 1，随后钓满 30 秒并得到 `(O)147`；只有物品成功交给库存后才记录渔获 |
| 空闲自主提议 | 没有玩家新指令时，模型主动提出“先陪你钓一会儿，再一起坐着发呆”并生成钓鱼＋休息协商卡 |
| 强制与跨场景等待 | 强制执行“挖 2 块 → 钓鱼”；农场完成前两次后因无水域等待，玩家带到海边后继续完成；亲近感按动作下降，不额外奖励原生好感 |
| 原生矿洞 | UndergroundMine5 的真实地图上完成 2 次挖矿＋30 秒保护活动；不以保护计时结束冒充击杀记录 |
| 重启恢复 | 保存的未完成约定在重新启动并读取 AgentLab 后变为 paused，进度保留；重新招募测试队伍、点击继续后完成剩余休息 |
| 邀请与离队 | 同一个 Leah 对象可以离队；Squad 将其送回日程位置后，远程招募被正确拒绝；在实验中重新放到玩家身边后招募成功 |
| 英文游戏兼容 | 不改变游戏语言，独立加载自带中文字体；中文面板与对话能够正常显示 |
| UI | 从游戏实际 UI 渲染目标读取图像，检查聊天、人设、共同经历三页；未用模拟网页替代实际游戏界面 |

本轮 C# 模型管线共使用 4 次 DeepSeek Flash 请求，返回 usage 合计 9198 tokens；没有持续挂着的模型测试循环。模型交换条件与主动提议是实际 API 结果。多步动作、矿洞和恢复的重复验收也使用专用 `together_lab_plan` 固定计划，以隔离模型随机性；它们不冒充每次都由 LLM 生成。游戏测试通过不代表所有地图、所有 NPC 或所有模型回答均已覆盖。

发现并修正的问题包括：独立钓鱼被玩家停止钓鱼事件打断、战斗抢占后丢失原任务、游戏截图漏掉 UI 渲染层、新结识 NPC 没有原生好感条目、同一天重复载入恢复精力、聊天长消息被截断，取消时已完成动作的结果核对、英文游戏下中文字体缺失，以及底层寻路停滞检测和有限换目标恢复。

## 可重复检查

- `python3 -m unittest discover -s tests -v`：12 项既有 Python 检查通过。
- `work/dotnet/dotnet run --project tests/Together.DomainChecks.csproj`：9 组 C# 检查通过，覆盖非法模型计划、逐步完成、序列化进度、强制状态、精力边界、同日重载与跨天恢复。
- `python3 evals/companion_control.py`：真实游戏 8 项控制检查通过，包含幂等、过期目标、冲突 ID、会话和取消。
- `python3 evals/together_control.py`：真实浇水/收获效果、离队和远程招募限制检查通过。
- `python3 scripts/build_companion.py`：Together 自有项目编译零警告、零错误；上游 Squad 保留其原有编译警告。

运行游戏检查前必须用 `scripts/launch.py --lab --companion`，加载 AgentLab，到 Farm、关闭面板、停止已有约定。脚本会重置实验地块，不应用于个人存档。

原始本机证据保存在项目忽略提交的 `work/together-*.json`、`outputs/*report.json`；交付目录另提供筛选后的验收数据。API Key、请求头、个人存档和未经筛选的运行日志不作为交付证据。

## 交付边界

可玩的单人 0.1 版，不是无人值守全游戏机器人。玩家负责跨地图带路、上下矿层；没有独立远程路径规划、建造、种植、语音或多人同步。模型偶尔会把计划说得超出工具能力：现已明确约束原地休息等技能语义，并始终以程序验证的实际结果更新进度，但不宣称语言绝不出错。

正常使用的记录与游戏存档独立持久化；未保存退出导致游戏世界回退时，记忆仍可能保留此前发生的经历，未完成动作需重新核实。上游许可与整合方式见《同行来源说明》；本次没有对外发布整合包。
