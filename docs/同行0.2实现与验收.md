# 同行 0.2：实现与验收记录

日期：2026-09-19。此版本是完整设计的实施阶段，不是完整产品验收完成。

## 已落地的行为

1. **持续的自主生活**：兴趣、陪伴和换活动的需求随游戏时间变化；形成个人心愿，从当前可执行候选中选择活动并直接执行。每个角色有独立状态、失败冷却和安排。模型错误或额度不足时可以继续进行本地选择，明确记录决策来源。
2. **可打断的安排**：玩家任务可以中断自主活动，旧安排进入暂停队列；处理完后重新核对环境并恢复。疲劳会让自主劳动插入休息。已有玩家约定不能被普通自主决策覆盖。
3. **实际分工**：不再强制让工作的 NPC 追着玩家跑。农务包括浇水、收获、抚摸农场动物、收取已经完成的机器产物。玩家离开地图时，NPC 可以继续已有劳动。
4. **正常出口导航**：通过已有 warp 边走到地图出口再切换地点，不使用任意位置传送兜底。增加回农场处理分工、满足兴趣时前往海边的候选目标；出发前必须能找到路线。尚未覆盖所有门、矿洞楼梯与特殊交通。
5. **共同项目与真实资料**：可持续安排农场照料，也可准备一项献祭。读取实际普通/混合献祭数据、任选槽位、品质和库存缺口；读取任务类型和公开条件、收集/技能/成就计数、作物、动物、机器、箱子、玩家与队伍库存。备齐材料不等于提交或完成。
6. **朋友式表达的基础**：经历按实际动作结果生成，碰面时分享一次；有每日傍晚碰面的习惯、个人心愿、可编辑人设和共同项目。安静地做事也是正常结果。自主邀请有过期时间，不会永远卡在等待同意。
7. **游戏内界面**：F8 增加“心事”和“农场”，显示活动理由、心愿、需求、分工、缺口与生活节奏。
8. **可靠保存**：状态随游戏保存，过夜前处理进行中的动作；用量账本独立保存，防止读档重置已消耗额度。旧版独立记录只作首次迁移来源。

## 完整设计中仍未完成的部分

| 任务与发展 | 每类普通任务的完成归属测试、特殊订单、Joja 项目推进、长期项目依赖图；当前主要是读取与献祭准备 |

| 保存恢复 | 七次过夜已验证；进行中活动的全部读档时点、所有异常恢复组合仍需扩展 |
| 长时质量 | 连续七天自然游玩、性能采样、不同存档与真实用户试玩尚未完成 |

普通水域的 NPC 鱼表调用绕过了玩家首次钓鱼教程的兜底逻辑，避免因为玩家没亲钓过就不断走教程流程。渔获进入物品库存，不伪造玩家亲钓统计或直接完成成就。特殊地图与依赖玩家精确位置的稀有条件仍需专项适配。

特别说明：NPC 的部分工具能力和战斗规则来自 Squad；尚未完成独立装备、完整物资所有权及所有消耗项审计。献祭预留目前是规划提示，没有销售或支出执行器，所以不会自动花钱或卖出物品。

## 结构与复现

- `Life.cs`：需求、愿望、经历、项目与可测试候选选择。
- `LifeRuntime.cs`：游戏循环、自主模型决策、安排中断恢复、分享、共同项目和过夜检查点。
- `WorldReader.cs`：只读事实快照，使用真实世界与存档对象。
- `UsageLedger.cs`：模型用量账本，与游戏进度回退分离。
- `OwnedMovement.cs`：角色自主控制、正常出口导航与机器交互。
- `evals/farm_care.py`：专用存档的动物、机器实机检查。
- `evals/journey_fishing.py`：跨四张地图、合法钓位、玩家离屏时持续钓鱼检查。
- `tests/TogetherDomainChecks.cs`：纯 C# 行为检查。

开发复现（在项目目录，先退出正在运行的隔离游戏）：

```sh
python3 scripts/build_companion.py
work/dotnet/dotnet run --project tests/Together.DomainChecks.csproj
python3 scripts/launch.py --lab --companion
```

实机检查只在加载 `AgentLab_449404282` 后执行，脚本会改变专用测试场景，不用于个人存档：

```sh
python3 evals/companion_control.py
python3 evals/together_control.py
python3 evals/farm_care.py
python3 evals/journey_fishing.py
```

这些实机脚本应逐项运行并核对其初始场景要求；它们不是无前置条件的一键全测。

运行仍为 Together + 本地适配 Squad。StardewValley-MCP 和 AI Dialogue Mod 是参考来源，没有额外运行两个控制器争抢同一个角色。正式入口不包含开发 Bridge。

这是本地阶段交付。没有上传、公开发布或把未实现能力写成已完成。
