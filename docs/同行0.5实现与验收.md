# 同行 0.5：共同手册实现与验收

日期：2026-09-19。环境：macOS，Stardew Valley 1.6.15，SMAPI 4.5.2，Together 0.5.0，Squad 0.12.1 适配版。

## 实际交付

F8 面板右上角新增“共同手册”。在同一入口融合百科资料、实时农事提示和日历安排，玩家与伙伴使用同一个 KnowledgeService。

当前原生测试环境读取到 1,353 条条目，包含物品、种子/作物、鱼类、人物、配方、机器/设施、地点和自编机制说明。数量随游戏内容与内容 Mod 改变，不是手写的固定数据库。任务与献祭进度通过实时页面读取。

- 搜索：ID、名称、英文内部名、已配置别名、前缀/包含匹配、一个字符的轻量错字匹配；歧义和错字只产生候选。中文机制问题用关键词/主题映射，季节种植及部分鱼类问题用结构化筛选。
- 资料：物品用途、基础价格、种植资料、配方材料、库存位置、预留提示、人物原生关系和已知礼物、机器实际加工状态。
- 农事：现有作物实际阶段、浇水/收获/照料/喂养/机器收取数量、当季日历、人物生日、标准节日及可读取的跨日活动、原生明日天气。
- 共同生活：收藏、最近阅读、便签、相关条目、献祭/制作备料目标衔接；收藏物资满足共同需求时可在原有频率与安静模式约束下分享。
- 模型：查询先取得有来源的事实；未命中可让模型改写一次查询词，再读取并回答。一次问题最多两次模型请求，消耗既有每日额度，不能直接派工或改变预算。
- 可追溯：事实卡标明来源、观察时间、完整/随探索范围，以及无法完整判断的规则。模型没有可核对的来源 ID、生成未提供的数字或服务失败时回退本地资料。
- 保存：收藏、便签、近期条目和发现记录随原生保存；数据格式升级为 schema 4，保留原保存键，旧记录获得默认值，旧版 Together 的版本保护会阻止回写新格式。

采用 C# 内存字典与轻量搜索；没有 BM25、向量数据库、embedding 模型或常驻 Python 服务。索引分批构建，资料失效/语言变化后重建，搜索不在每帧全量执行。

Lookup Anything、UI Info Suite 2、Almanac 是功能与设计参考。当前 Provider 为本项目实现，直接读取运行时游戏数据；没有复制或打包三个参考 Mod，也无需安装它们。可选 F1 联动按 Lookup Anything 的公开悬浮对象约定实现，未在本次正式两 Mod 组合中验证。

## 能力边界

1. 这是三类功能的统一实现，不是三个完整 Mod 的全部能力复制。树木生长阻碍的逐项诊断、所有装备/装饰资料、所有自定义机器条件等尚无全面适配。
2. 新种作物给出基础日历与明确假设；没有完整模拟肥料、职业、水稻、温室和所有自定义季节规则。已有作物读取实际阶段，因此能反映种下时已生效的阶段调整；仍不预测后续断水或死亡。
3. 鱼类读取静态地点规则，核对季节、时段、天气、等级、捕获上限及部分装备。特定落点、水域、额外解锁、动态物品查询、特殊地点覆盖与随机概率保留部分支持标记，不承诺肯定捕获。季节筛选只纳入可直接解析的明确季节规则，结果不是完整鱼种清单。
4. 库存观察覆盖玩家、队友物资及农场/建筑内读取到的容器，不能把“未观察到”说成整个世界没有。礼物推荐主要围绕当前已观察库存，随探索模式不泄露未知偏好。
5. 模型有出处约束与数字检查，但不构成对所有自然语言断言的形式化验证；事实卡是核对依据。语义很模糊时可能需要重述或选条目，不使用向量召回兜底猜测。
6. 本次为原生内容、单人专用 AgentLab 验收。未宣称验证所有多人场景、手柄、分辨率、大型内容 Mod、Lookup Anything 同装组合或长期真人趣味体验。界面自动化验证以渲染与菜单处理器为主，不将其冒充真人连续试玩。

## 复现与使用

玩家：双击本机“同行体验版/启动同行.command”，进入存档后按 F8 → 共同手册。

开发验收：

```sh
work/dotnet/dotnet run --project tests/Together.DomainChecks.csproj -c Release
python3 -m unittest discover -s tests -p 'test_*.py'
python3 scripts/launch.py --companion --lab
```

在隔离游戏的控制台用 `agent_load AgentLab_449404282` 加载专用测试存档，等待资料索引就绪。再运行：

```sh
python3 scripts/check_knowledge_runtime.py --models
```

`--models` 使用已配置的接口，会实际消耗少量模型额度。脚本只通过受 AgentLab 限制的本地接口操作，不打印密钥。测试会写测试便签和收藏，不适用于真实玩家存档。日常体验包不包含 AgentBridge、测试配置、个人存档或密钥；原有 Squad 再分发限制仍见来源说明。
