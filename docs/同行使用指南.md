# 同行 · Together 0.4

同行是一起经营农场、各自有兴趣和安排的 NPC 陪伴 Agent。游戏状态、地图、路径和动作由 C# 处理；DeepSeek Flash 负责选择活动与聊天。无需视觉模型，也无需常驻 Python 服务。实际运行的是 Together 与适配后的 The Stardew Squad；MCP 和 AI Dialogue 的设计作为参考，没有同时启动三个角色控制系统。

## 第一次一起玩

1. 退出星露谷，双击本机体验目录的 `启动同行.command`，进入单人存档。
2. 走到 NPC 身边，按 **F8**，选中角色，点击“邀请同行”。
3. 在“人设”选择农场伙伴、钓鱼搭子、冒险搭子、贴心恋人或慢热朋友，也可以编辑自己的设定。称呼不改变原生婚姻。
4. 开启聊天页的“自主生活”，关闭面板。它会开始考虑自己的活动，不必等你逐项批准；默认至少间隔约 90 秒，性格会调整间隔。
5. “心事”展示当前打算、原因、需求和随身物资。“相处”可选择平常、安静或放假一天。

本机体验配置允许提前邀请符合条件的角色，不直接增加原生好感；仍受距离、剧情与队伍容量限制。面板按 1280×720 或更大的游戏界面验收。

先玩十分钟：一起去水边，聊天说“你先钓一会儿，我忙完过来”；回来问“刚才怎么样”。也可以请它做一点农活，然后让它自己安排下一段时间。没钓到东西也会如实记下，不保证每次都有收获。

## 让它分担农场

先在“农场”点击“一起管农场”，选择慢慢生活、劳逸结合或推进目标。常规浇水、成熟作物收获、动物照料和机器成品收取，会进入每天更新的安排。

在普通箱子旁点击“切换附近箱子用途”，依次是：不使用 → **原料箱** → **收货箱** → **待售箱** → 不使用。

- 原料箱：允许取实际种子和加工配料。物资先被取到伙伴随身库存，再走到目标处使用。
- 收货箱：接收伙伴实际拿到的农作物、渔获、矿物等。取消任务不会凭空销毁携带物资。
- 待售箱：允许把未被项目预留的可出售物品运到农场出货箱，收入在原生过夜结算时到账。

“经营 → 地块”：站在计划区左上角，选择种子，划定向右、向下的 3×3 地块。可以另外开启这些地块的杂草、树枝清理；不砍树、不拆设施。只翻空地和播种，不拆设施、不铲已有作物。原料不足、地块不适合或换季前来不及成熟时不会强行播种。

“经营 → 购物与预算”：填写每天最多花多少、至少留下多少，再添加种子或干草清单。默认预算为零。只购买清单里的东西；核对营业状态、实际店员、原生价格、存货和数量上限。清单完成后不会第二天再次买一遍。

已有鸡舍或畜棚时，伙伴能走门进入，抚摸动物、添真实干草，以及处理可挤奶、剪毛的动物。机器补料使用原生配方与时间，不会瞬间变出成品。

## 共同目标和朋友的生活

“经营 → 共同目标”能选择存档中读到的任务、特殊订单、发展和制作目标，再决定谁负责。献祭在“农场”页添加。项目会计算缺口、保留所需品质与数量；多余同类材料仍可使用。“今日分工”展示准备事项与依赖。

**材料备齐不等于任务完成。** 献祭提交、NPC 交付、特殊订单提交、配方制作、建造、购买发展项目和剧情选择，由玩家完成。伙伴准备可执行的材料、陪同和提醒；不会修改完成标记，也不会把 NPC 钓鱼说成玩家亲手钓鱼。支持情况和归属证据见《验收与限制》。

伙伴有精力、兴趣、陪伴和换花样的需求。偏好、个性、关系、当前安排和共同目标影响选择。喜欢钓鱼的朋友可能自己去海边，也可能先帮你收好农活再去。请求与偏好冲突时，可以接受、商量或拒绝；“强制”绕过意愿判断，但仍遵守物资、路线、预算等实际限制，每个约定只结算一次关系影响。

邀请过的长期伙伴会在早晨重新加入，并沿正常路线过来；选择“各忙各的”后不再自动加入，直到你再次邀请。

玩家新请求可以暂时打断自主活动，处理后尝试继续；已完成动作不会重做。计时活动保留未完成时长。明确的玩家约定不会被普通自主提议覆盖。

“相处”包含：

- **安静陪着**：暂停普通主动分享，仍能做事，不会扣关系。
- **放假一天**：今天减少共同劳动，更多选择兴趣与休息，隔天恢复。
- **真实日记**：根据已发生的活动写下当天记录，未完成的事不会写成成功。
- **共同小习惯**：同地点、同活动有三天自愿相处记录后，可以确认或暂停。
- **三天收获挑战**：你钓到一种新图鉴，伙伴带回一份真实渔获，各自分享，不比较效率。
- **小礼物**：在你指定的收货箱放一件自己实际拥有、未预留的鱼或花，不凭空生成。
- **性格维度**：主动、社交、风险、耐心、计划可以调整。

聊天输入 `记住：我喜欢雨天慢慢钓鱼` 记录偏好；`忘记：雨天` 删除匹配偏好；`日记：今天一起收菜很开心` 为当天日记添加玩家留言。“导出经历”生成不含密钥的本地 JSON；“清除这位的记忆”清除聊天及衍生记忆，关系和当前任务保留。

普通主动话题最多每天三次，并间隔至少三分钟实际游戏时间。任务答复、任务失败和玩家主动聊天不占这个普通话题上限。伙伴会记得没聊完的话题，但不会反复催你回应。

## 动作、路线与失败

移动沿地图格子和正常出口进行；挖矿、翻土、浇水等有动作过程，效果在执行阶段结算。钓鱼是持续活动。普通矿洞支持已出现的向下楼梯、离矿出口和已解锁电梯楼层；没有楼梯或未解锁的层不能直接跳过去。

战斗由快速规则处理，结束后恢复被打断的工作。不会用随意瞬移掩盖卡住；目标改变、材料被拿走、路线封死、箱子满时，会停止、重试可达目标或说明困难。离队沿路回自己的日程地点，到达后结束同行。

本轮面向普通单人地图。多人、沙漠/骷髅洞与姜岛特殊交通、所有扩展地图、任意剧情和节日小游戏不在支持范围。无法到达时请使用原生游戏方式移动或带队友前往可通行区域。

## 保存、模型与安装

人设、关系、日记、项目、物资及安排随游戏正常保存。未保存退出后，记忆随世界一起回退。读取旧记录时迁移，遇到更新版本的数据停止覆盖。导出不能代替整个游戏存档备份。

模型用量按存档、玩家和游戏日记录在 `Together/usage/`，重载不会返还已用额度。默认 DeepSeek Flash，每游戏日最多 24 次，30 秒超时，回答最多 700 tokens；实际费用以服务商计费为准。额度不足或自主决策失败时，会从当前可执行活动里选择本地备选；失败的玩家聊天不会被当作已经接受任务。

本机启动配置读取项目 `.env`，交付包不复制 Key。换电脑时，在 Mod 本地 `.env` 设置 `DEEPSEEK_API_KEY` 并调整 `ApiKeyFile`。人设、相关记忆和游戏状态文本会发送到该模型服务。

本机入口加载 Together 与适配后的 Squad，保留原游戏 Mods 目录。依赖其他 Mod 的个人存档仍需其原有依赖；建议先用单独体验存档。正常体验包关闭实验接口，不含测试桥、个人存档和游戏 DLL。

`Together-0.4.0-own-code.zip` 是自有 Mod 包，另需适配后的 Squad。第三方来源与发布许可见《来源说明》；完整本机体验目录不能直接当作可公开分发的开源整合包。

功能验证与主观趣味是两件事。技术结果、具体失败修复和尚需真人评价的内容，统一记录在《验收与限制》，不会用“模型说成功了”代替游戏证据。
