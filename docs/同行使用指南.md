# 同行 · Together 0.1

一个读取游戏状态、有人设与共同记忆的星露谷陪伴 Agent。当前版本用于单人游戏；正式游玩由 C# Mod 直接连接 DeepSeek Flash，不需要 Python 服务，不使用视觉模型。

## 在这台 Mac 上开始

1. 退出其他星露谷游戏进程，双击交付目录 `同行体验版/启动同行.command`。
2. 进入自己的单人存档，走到可招募 NPC 身边，按 **F8**。
3. 点击“换个队友”选中附近角色，再点“邀请同行”。默认允许低好感试玩；仍受 Squad 的可招募角色、事件和队伍容量限制。
4. 在“人设”页选择预设，或编辑关系称呼、性格、喜欢、不喜欢与说话方式，点击保存。
5. 发一句话。发送后面板会关闭，游戏继续运行，NPC 以头顶对白回答；F8 可查看完整聊天与约定进度。

启动入口使用独立 Mod 目录，保留原有 Mods。该入口只加载 Together 与本地适配的 Squad，不加载 AgentBridge、测试控制台、Farmtronics 或其他原有 Mod。依赖其他 Mod 的旧存档仍应在原有配置中游玩；这个入口建议先用普通新存档体验。关闭游戏后正常从 Steam 启动即可回到原有配置。

本机启动配置引用项目自己的 `.env`，Key 没有复制到交付目录。迁移其他电脑时，在 Together 文件夹建立 `.env`，写入 `DEEPSEEK_API_KEY=你的Key`，并把 `config.json` 的 `ApiKeyFile` 改成 `.env`。

## 三个值得试的玩法

- **钓鱼搭子的交换条件**：设为“钓鱼搭子”，说“帮我挖两块石头，之后陪你做喜欢的事，你想怎么安排？”它可能接受、协商或拒绝。出现协商卡后点“同意约定”，带它到需要的地方。
- **你的冒险搭子**：设为“冒险搭子”，说“陪我下矿，帮我挖两块石头，再保护我一会儿”。玩家负责带路和上下楼；队友根据真实地图找目标、寻路、执行，附近遇怪优先应战。
- **有主见的亲密陪伴**：自定义称呼、偏好和风格，例如“恋人、喜欢钓鱼、怕连续挖矿、爱开玩笑”。一起完成约定会留下记忆；之后的聊天会收到近期经历、心情和真实好感作为上下文。自定义称呼不改变游戏婚姻。

行为不是固定台词，模型不保证每次都拒绝或给出同样的交换条件。空闲时允许主动聊天、提出小约定，偶尔主动帮小忙；面板可随时关闭“主动提议”。

## 活动与操作

| 活动 | 当前行为 |
| --- | --- |
| 挖矿、浇水、收获 | 从真实地图选择附近可达的单个目标；一次约定每步 1–5 个、最多 3 步 |
| 钓鱼 | 自主找附近水边站位并钓 30 秒；按游戏地点、季节等抽取渔获，可能空军，也可能是杂物 |
| 保护玩家 | 跟随并利用 Squad 的战斗执行器应对附近怪物，持续 30 秒；不等于保证玩家不会受伤 |
| 休息 | 在当前区域休息 20 秒，恢复本 Mod 的精力；不会自动走到指定景点或坐上椅子 |
| 跟随 | 切换回跟随模式，跟着玩家跨场景；不宣称已经走到某个目的地 |

“同意约定”执行协商方案；“下次吧”拒绝提议；“停止”取消任务并恢复跟随；“继续”恢复暂停或等待的约定。对方已明确拒绝时，普通同意不会派工，必须点“强制”。强制会降低本 Mod 的亲近感，不增加原生好感，也不会绕过不可达、任务能力和场景限制。

底层行动停滞约 8 秒时会终止该目标，并最多换目标重试 2 次。没有目标或水域时会等玩家带路，约 180 秒仍无条件则结束并记录未完成。跨场景重新选目标；遇怪可保留任务并恢复。重新载入存档后，未完成约定先暂停，点继续才重新核实环境，避免重复派工。

“亲近”与“精力”是本 Mod 的状态。真实原生好感、约会和婚姻会读取给模型；正常兑现约定可增加少量原生好感（一次 +2 点、每日最多 +6 点），强制不奖励。活动改变精力，跨天恢复。

## 模型与数据

默认 `deepseek-flash`，异步请求，30 秒超时；每天最多 24 次请求，单次输出最多 700 tokens，空闲检查至少间隔 30 秒（默认 90 秒）。每个新环境组合只主动询问一次，已有任务或未处理提议时不反复询问。请求会消耗你的 DeepSeek 额度。

发送的是人设、近期聊天与共同经历、附近可执行目标、好感、地图名、健康和附近威胁等文本状态；不发送 Key 到提示词、不发送游戏画面。网络失败不派工；快捷活动仍可用。

记录保存在 `Mods/Together/data/`，按游戏存档 ID 和玩家 ID 隔离，最多保留每人 60 条聊天和 60 条经历。损坏记录会停止写入，保留原文件。记录是独立文件：退出而不保存游戏可能使游戏世界回退，但聊天历史仍保留。取消加载中的回复后，它不会再触发行动。

## 当前边界

这是可玩的本地 0.1 版，不是覆盖全部星露谷机制的通用玩家。尚未实现独立跨地图寻路、自动下楼、建造、种植、礼物系统、语音、长期故事导演和多人联机。需要玩家带路；部分 NPC 的技能受 Squad 自身角色配置限制。动作结果有核验，语言表述仍受模型影响。

`Together-0.1.0-own-code.zip` 只包含本项目新 Mod，不是独立完整安装包；它需要已准备的 Squad 适配版本。这台 Mac 请直接使用 `同行体验版` 文件夹。上游来源与本地整合范围见同目录“来源说明”。
