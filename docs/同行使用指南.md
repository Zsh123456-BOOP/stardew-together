# 同行 · Together 0.3 阶段版

这是一个用真实游戏状态驱动的 NPC 陪伴 Agent：C# 负责地图和动作，DeepSeek Flash 负责选择与聊天。无需视觉模型或常驻 Python 服务。0.3 加入指定箱子的物资管理、机器补料与经历检索；完整设计仍有未完成项，见《同行0.3实现与验收》与前一版记录。

## 开始体验

1. 退出星露谷，双击本机体验目录的 `启动同行.command`。
2. 进入单人存档，走到 NPC 身边，按 F8，选择角色并点击“邀请同行”。
3. 在“人设”页选择钓鱼搭子、冒险搭子、农场伙伴或自定义性格。关系称呼不改变游戏婚姻。
4. 打开“自主生活”。关闭面板，让游戏继续运行；模型决策默认至少间隔 90 秒。暂停菜单中不会继续劳动。
5. 在“心事”看它的计划、原因、个人心愿；在“农场”选择共同照料农场或准备一项献祭，并选择慢生活、劳逸结合或推进目标。

普通个人活动直接执行。邀请你共同参与才会提出约定；被忽略的自主邀请会在约 30 游戏分钟后过期，伙伴继续自己的安排。玩家提出新任务可以打断自主安排，做完后尝试继续。玩家已有的明确约定不会被普通新安排覆盖；先停止或明确强制。

可尝试：

- 农场伙伴：点击“一起管农场”，让它自行选择成熟作物、浇水、抚摸动物或收机器，然后自己去别的地图。
- 钓鱼搭子：带到有可达钓位的水边，允许自主活动；它能自己开始钓鱼。期间叫它休息，再观察是否继续原计划。
- 聊聊共同目标：“我们接下来一起管好农场。”“看看献祭还缺什么。”模型会收到真实农田、物品、任务和献祭资料。

## 当前动作

| 动作 | 当前实现及边界 |
| --- | --- |
| 挖矿、浇水、收获 | 真实地图目标、行走、前摇、实际效果与回执；自动计划可一次处理多项 |
| 抚摸动物 | 只处理角色同地图的可达农场动物；动物移动时重新获取目标 |
| 收机器 | 收取已经完成的产物，放入玩家背包；背包或机器拒绝时报告失败 |
| 给机器补料 | 步行到指定原料箱取配料，再到机器投入；使用真实原料和原生加工时间，已实测普通熔炉 |
| 存放携带物资 | 走到指定收货箱存放；途中取消或满箱保留物资，心事页可以查看 |
| 钓鱼 | 选择附近钓位，持续钓鱼；可能空军，不保证稀有鱼；渔获沿用 Squad 的队伍库存机制 |
| 保护、休息 | 附近危险由 Squad 战斗处理；原地休息恢复本 Mod 的精力 |
| 跟随与出行 | 单独的玩家跟随指令会持续到改变安排；沿已存在的地图出口通行；没有出口边的门、矿洞楼梯、矿梯及特殊交通尚未完整适配 |
| 离屏农活 | 已验证玩家在 BusStop、NPC 留在 Farm 完成真实浇水 |

不要以为“跟随模式开启”就代表已经走到你身边。资源动作最多换目标重试两次；长时间无法完成会记录失败。完整地图上尚未验证的路径不会被瞬移兜底伪装成功。离队仍保留 Squad 的回家处理，尚未改为全程步行。

自主劳动累了会停下休息。强制是每个明确约定扣一次本 Mod 亲近感，不会每浇一株都扣。普通共同任务的原生好感奖励保持每日上限；本 Mod 不给自己的劳动额外计共同好感奖励；Squad 自身的好感规则仍保留。

## 共同经营和进度

读取农田、农场与建筑内可见箱子、机器、动物、玩家物品、队伍库存、已接任务、实际献祭数据以及收集/技能/成就计数。献祭使用存档中的要求，保留任选槽位与品质条件；材料备齐不等于已完成，提交由玩家进行。

“共同农场”是每天更新的持续安排。计划卡可以暂停和继续；暂停后续计划不会立即终止手头动作，需要立即停下时使用聊天页的“停止”。献祭项目保存所选材料缺口，并保护对应品质的物品不被补料消耗。当前采取保守预留，还不会精确释放同类富余材料。自动购物、卖货、播种和预算执行尚未接入，因此不会自行花钱或销售材料。普通任务会读取具体条件，但尚未逐类实现全部交付与归属测试。

在普通箱子旁点击“切换附近箱子用途”，按不使用 → 原料箱 → 收货箱 → 不使用切换。原料箱允许给机器补料时取出实际所需配料；收货箱接收伙伴已经携带的材料。没指定的箱子不能用于这些操作。材料在路途中属于伙伴的真实库存，取消后可以继续补料或叫它存好；不是直接从远处箱子隔空扣除。尚未统一所有农活和钓鱼的产物去向。

## 保存、模型与隐私

- 人设、关系、记忆、心愿、项目和安排随游戏正常保存，使用 SMAPI 存档数据；未保存就退出会随游戏世界一起回退。
- 首次使用会尝试迁移旧版 `Together/data/` 的记录，保留原文件。
- 模型用量单独写在 `Together/usage/`，按存档、玩家和游戏日隔离；读档不会重新获得当天已消耗的调用额度。
- 默认 DeepSeek Flash、每游戏日最多 24 次调用、30 秒超时、输出上限 700 tokens。输入为人设、记忆及游戏状态文本；实际成本以服务商计费为准。
- 自主决策遇到错误或额度不足时，程序从当前可执行活动中继续选择，日志会区分模型选择和本地兜底。玩家聊天失败不会被当成已经接受了任务。
- 本机配置读取项目 `.env`，交付目录不复制 Key。迁移电脑时自行在 Mod 的本地 `.env` 配置 `DEEPSEEK_API_KEY`，并调整 `ApiKeyFile`。

## 安装范围

本机启动入口只加载 Together 与本地适配的 Squad，保留原游戏 Mods。依赖其他 Mod 的个人存档仍需要原有依赖，建议先使用普通新存档体验。现阶段只支持单人。

`Together-0.3.0-own-code.zip` 只有本项目新 Mod，仍需要单独准备 Squad 适配版本。本机使用已经配好的体验文件夹。完整故事、所有任务代办、所有地图与多人模式并没有完成。

开发时先关闭隔离游戏再构建；构建脚本和启动脚本现在会互斥。测试初始化与录制只允许 AgentLab，正常版不开放这些命令。
