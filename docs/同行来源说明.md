# 来源与整合范围

`同行 · Together` 的 UI、人设、模型接入、约定调度、自主需求、共同项目、经历检索、关系更新、游戏状态读取、数据保存、物资流转与执行回执适配为本项目新增 C# 代码。

实际运行依赖 [The Stardew Squad](https://github.com/Isalda/the-stardew-squad)，固定提交 `a9084ef4f258325e9a7d589685cec6c3f6cdbad9`。基础 A*、NPC 动画、基础战斗、农务、钓鱼与队伍系统由 Squad 提供。本项目在本机构建副本中加入 API、托管控制权、正常出口跨图、通行修复、动画前摇、独立物资任务与完成证据 hooks，并调整独立钓鱼调用；保留原作者与资源说明。源码克隆中的运行代码没有修改，变更由本项目构建脚本可复现地应用到临时副本。

[StardewValley-MCP](https://github.com/amarisaster/StardewValley-MCP) 与 [StardewValleyAIDialogueMod](https://github.com/phenyisole/StardewValleyAIDialogueMod) 用于前期源码研究与职责设计，没有把其伙伴系统或聊天源码直接复制、同时启用。正式版用同一个 Squad NPC，通过 SMAPI 进程内 API 调用执行器，避免三个控制器争抢角色；开发版仍可使用原有本地 HTTP 工具桥。

Squad 的本地测试目录已按用户要求移除；本项目用于验证约定与真实行为的少量自有检查保留。第三方源码固定版本和准备方法在 `configs/companion-upstreams.json`、`scripts/prepare_companion_sources.py`。

当前克隆中 Squad 和 AI Dialogue 没有发现明确仓库许可证；此前核验的 Squad 发布页要求修改前取得许可。MCP 仓库 LICENSE 与 README 许可表述不一致。因此本次交付是用户本机研究和体验版本，没有对外发布或向作者发送消息。含 Squad 的本地体验目录不得当作已取得再分发许可的公开安装包。独立 ZIP 仅放本项目 Together 代码产物与说明；若将整合版公开发布，需先解决相应上游许可。

游戏 DLL、游戏资产、个人存档、密钥、运行数据和本地编译产物不进入 Git。截图仅用于本次 UI 验收和本机说明。
