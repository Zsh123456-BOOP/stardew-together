## 旁路与事实来源审查

| 项目 | 入口/旁路处理 | 事实来源 |
|---|---|---|
| 制作 | 菜单与执行器共享 ValidateRecipe，原生扣料仍由执行器执行；失败只关闭自己拥有且无手持物的菜单 | 原生配方、CapacityAdapter、原预留校验 |
| 采购 | 菜单购买转交 player.buy，必须携带与所选报价匹配的显式预算；未知付费问题和专用交易菜单拒绝通用点击 | 同一个原生 ShopMenu 和 PlayerShopping |
| 无效果 | 执行控制层计数、同步留证暂停并锁住后续 Choose；模型同轮后续调用也停止 | 点击前后菜单/手持物/库存/计数快照 |
| 手持物 | Start 拒绝开启另一动作；menu.close 保留手持物；菜单只允许原生背包交接 | 原生 heldItem，不写第二份预测库存 |
| 仓储 | 复用既有 AutoExpand/木材预算与目标依赖链，解除对经营政策启用的附带依赖 | SharedStorage、真实配方、放置回调 |
| 经营 | 显式启用候选→既有 ConfigureBusiness→投资→原生服务→报价→原生购买 | 原生季节、现金、可照料容量；不自动启用支出政策 |
| 空间 | Ready 的可执行集合先排序，再单角色选单；每日农务先生成，清理新出行不沿用旧片区；父任务内卸货仍保留片区 | 原任务依赖和时窗＋当前地理位置；没有改 BFS 或开发清障寻路 |
| 百科/任务 | 仅索引可见条目、已批准且有未解决依赖的目标、真实已接任务或已打开任务板生成查询 | 已有 Knowledge/Progress/Quest 读取，不新增知识库 |
