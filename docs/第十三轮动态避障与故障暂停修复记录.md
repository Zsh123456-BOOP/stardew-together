## 已实现

- [x] 多点路线移除当前所在格这一多余起点；最终目的格仍由原生到达判定验证。
- [x] NPC 挡住实际下一步时，按玩家真实碰撞框搜索局部像素路径。每段扫过中间位置，同时校验地形、对象和 NPC；移动调用原生 `MovePosition`，不改位置、速度或通行权。
- [x] 局部路径每帧核对下一步，障碍变化则失效重算；搜索限定 128 像素范围与节点数，失败搜索最多每秒一次。不凭原先格子可达就向 NPC 持续施加同一方向。
- [x] 无局部通路时允许动态阻挡者移动，等待窗口由 0.35 秒改为 2 秒。仍有限重试，三次业务失败保护不删除、不清零。
- [x] 记录局部绕行起点、目标、步数、碰撞探测次数及计算时间，保留原有完整路线和动作回执。
- [x] 自动故障暂停及试玩完成时，独立暂停标记使原生 `shouldTimePass` 返回 false。不回写时间，不替换菜单，不覆盖其他暂停标记。恢复 AI、方向键接管、退回标题时解除；玩家主动接管不冻结时间。
