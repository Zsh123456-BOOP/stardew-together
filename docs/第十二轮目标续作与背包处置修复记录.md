# 第十二轮：目标续作、容量恢复与自主处置

## 范围与结论

本轮依据用户核对的优化清单实现。保持阶段 A：只控制玩家，小禾不运行；七天为用户观察试玩，不计入十四天闸门。

模型决定经营与物品处置，程序提供真实库存、用途保护、容量预测、原生执行及核验。不增加“失败后必须随便做另一件事”的轮换规则。

## 改动清单

- [x] `goal.create`：同一未完成实体、数量、完成条件、品质及设施策略，换请求编号也复用目标；新增独立需求需 `additional:true`。请求别名随目标保存，已完成目标不吞掉新的需求。
- [x] 目标准备先模拟下一原生操作容量；受阻返回真实缺口、下一动作与恢复信息，不生成新的采集需求。容量未满足时，位置、体力、木材数量变化不触发自动重试。
- [x] `inventory.capacity`：分别返回背包和共享仓库真实槽位、堆数、可处置数量、保护数量、价值估算、实际腾格预测与当前田块方案。
- [x] `player.discard`：从背包或指定箱子，通过原生垃圾桶销毁明确数量。仓库先真实走近、原生右键开箱，再用原生库存控件取出和垃圾桶处理；不直接删除库存数据。
- [x] 销毁前重读槽位、物品 ID、品质、堆数；保护工具、原生不可销毁物、任务物及已承诺材料。部分销毁不冒充腾格，仓库腾格不冒充背包腾格。
- [x] 每次销毁保留完整前后库存、实际销毁量、空格变化及原生垃圾桶回收金币；核验“前总量－明确销毁量＝后总量”，失败不伪报成功。已核验销毁写入幂等日记，面板显示对应操作。
- [x] 候选复用容量模拟；钓鱼候选必须存在从实际地图入口可达的原生抛竿点，不能仅凭 `canFishHere` 推荐商店内钓鱼。
- [x] 已有种子和有效田块方案直接提供 `work.run plant` 候选；`farm.plan` 返回明确的下一执行动作。异地查询返回“回农场→重新规划”前置步骤，旧声明层不再提前抹掉这些信息。
- [x] `running/queued` 回执标为 `in_progress`，`waiting` 明确等待；不再把进行中的任务同时标成失败。
- [x] 原有条件失败记忆、独立任务队列、任务恢复和原生生产接口继续复用；没有添加无依据社交的兜底，也没有强迫模型必须查询已知配方。
- [x] 按用户本轮明确要求，`ModelTokenBudgetPerDay=0` 表示总 token 不限额；用量账本与完整请求/响应记录保留。单请求协议大小和模型最大输出长度仍是请求有效性边界。
- [x] 增加一次性启动脚本 `scripts/start_unattended_trial.py`。启动后脚本退出，不轮询经营、不救场、不重启；Mod 按原生过夜计数，在指定天数后暂停，保留游戏窗口。

## 集中验证

**域检查实测**：436 条通过。覆盖未完成目标身份、运行中回执、57 木材扣 50 后仍占格、整叠种子消耗后可制作、部分销毁不腾格、继续堆木材不腾格，以及不限额仍记账、有限额仍拒绝超预算。

**构建实测**：Together 0 警告、0 错误；沿用固定版本上游与隔离 Mods，不修改 external 克隆。

**原生组合检查实测**：最终 24 项全部通过。同一游戏实例集中测试背包部分/整叠销毁、旧堆数拒绝、工具保护、目标重试、满包制作受阻、销毁腾格、原目标制作和放置、箱子部分/整叠销毁。

满包场景通过原生库存右键拆分已真实采集的纤维构造，拆分前后数量守恒；未生成物品或修改游戏计数。测试资产全部来自原生劳动。

首次组合检查保留在 `work/u12-combined-1/`：发现声明层提前拒绝异地规划，以及直接调用 Chest.checkForAction 没有原生右键状态，箱子未打开。修复为结构化前置回执、复用 NativeMenuInput.InteractWorld，并给开箱独立超时。没有开启模型试玩来绕过这些失败。

最终组合结果与原生回执见 `work/u12-combined-2/`。运行证据不进入 Git。

## 工具边界

`player.discard` 是垃圾桶销毁，不是扔地上再让自动拾取捡回。保护材料需调整原有项目用途，不能借换工具入口绕过保护；规划、估值和新建物品副本均不计入真实库存。

箱子处置目前面向已经识别的共享仓库；实际操作仍核验箱子、互斥锁、交互距离及物品快照。任何未接受的手持物保留现场，不丢弃或强塞。

已生成播种方案是可执行候选，不等于强制模型必须播种。工具不再混淆事实，但模型能否长期合理选择、运输与劳动收益是否改善，仍要看新试玩日志。不能用组合检查替代七天经营结论。

## 七天试玩与日志

从全新 AgentLab 起点开始，使用 deepseek-flash、正常游戏时间、单玩家，目标为七次原生过夜后第八天早晨。模型调用总量不限额由用户明确授权；密钥仍只读本地被忽略的 `.env`。

启动目录记录 manifest、DLL 摘要、起始世界、接管回执、目标日与 log-index。Mod 原生日志记录模型请求/响应、工具参数与回执、任务状态、候选采纳、路线、容量恢复、销毁前后快照、日记、收入与原生存档。完成事件为 `user_trial_completed`；异常和玩家接管照常暂停保留证据，不自动重启或拼接。

没有后台 Codex 监督任务；用户自行观察，后续按 run_id 检查日志。启动不代表七天已通过。
