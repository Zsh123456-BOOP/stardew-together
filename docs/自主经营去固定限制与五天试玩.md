# 自主经营去固定限制与五天试玩

本轮依据：用户确认的 11 点方案，并要求实现后从全新起点让 Flash 自主运行五个完整游戏日。阶段 A 单玩家；不提前做阶段 B 或 R-B1 清障寻路。正常时间，不拼接失败运行。

## 职责与实施清单

1. [x] 自主模式开放经营能力；区分工具可用与模型主动创建的持续经营例行。直接采购不再要求先启用投资策略。
2. [x] 清理只派发模型创建的订单。保留混合清障、拾取与卸货续接；片区内绕行成本过高时，与全范围最近可达目标比较，记录实际步数与切换原因。没有实现穿障寻路。
3. [x] 真实报价附生长期、基础售价、多次收获、照料天数、可购数量；模型选品。明确按模型给定顺序缩量，不替换作物，并回报请求量与接受量。
4. [x] 默认取消 24 株手动照料上限；-1 表示模型没有设照料上限。96 是单次布局计算规模，不是农场终身/每日株数上限；可继续分批布局。真实空间与当前可完成操作仍校验。
5. [x] 对外投资状态区分执行中、已完成、暂缓、受阻、等待选品；内部 done 不再直接代表对外完成。
6. [x] 面板仅当前工作、简短用途、真实队列下一项；有当前阻碍才显示，过滤技术片段；保留半透明和滚轮。不展示重复总任务或整段计划。
7. [x] 默认体力保留为 0，接受模型逐任务设定；农务预测仍提供，但不作为清理/采集隐藏预留叠加。进食仍遵守物品保护与真实消耗。睡眠由模型决定，早睡及未做农务在日志体现，不强制无价值劳动。
8. [x] 监督器停止默认仅暂停并留窗；退出需显式 --exit-on-stop。新增 --trial 标记用户指定试玩，不计入 14 天门槛。
9. [x] 现金读取原生值，采购日支出复用原生回执账本；候选预算区分实际支出、待执行采购、明确资金保留，不提前花预计收入。
10. [x] 默认每日额度 -1、保留金 0；模型可以调整。删除直接购买、建筑等工具暗含的 500 金默认保留，显式报价/本次支出上限与原生余额验证保留。
11. [x] 常用采购、日常例行、社交与库存工具直接可发现；工具搜索增加中英文用途匹配，零匹配返回实际百科/世界入口，不能永远空转。百科与真实配方系统复用。

当天事实日记和失败去重沿用已验证实现：购买/播种/存取等只记实际回执，同事件去重，历史收集量不等于现有库存。

## 工程纪律

每项同时检查旁路入口、事实是否多源、全局状态不变量。物品守恒、原生扣料、手持产物保护、AgentLab 三重门禁不变。纯算法 AutonomyPolicy 显式注册到 DomainChecks。

现有存档中模型明确设定的策略不会被悄悄清空；新默认用于全新起点，已有策略可通过工具改为 -1 / 0。测试不能把旧存档里的显式设置误认作新默认。
