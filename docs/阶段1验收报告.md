# 阶段 1 验收报告

实测日期：2026-09-18。macOS arm64，星露谷 1.6.15 build 24356（x86_64），SMAPI 4.5.2，固定 Farmtronics 源码与本项目控制适配。

## 结论

单机器人非视觉闭环已经在真实游戏中运行。由 Codex 提供结构化任务计划，执行器读取游戏状态、寻路、执行、验证并处理暂停或障碍；未接入外部模型服务。

## 固定测试条件

- 独立 AgentLab 角色，当前地图为 Farm。
- 显式测试夹具放置 12 株作物，其中 6 株成熟；放置两台初始工具齐全的机器人。
- 游戏时钟冻结，便于重复验证，不评估跨日、疲劳恢复或长期经济策略。
- 所有计入任务的移动、浇水、收获和拾取均走正常游戏行为；初始化与任务执行分开记录。
- 背包数量按实际读取验证，不只检查作物是否消失。

## 结果

| 场景 | 结果 | 证据 |
|---|---|---|
| 完整任务，第 1 次 | 通过，25.85 秒 | 50 个低层动作；12 次浇水，6 次收获，收到 6 个防风草，返回起点 |
| 完整任务，第 2 次 | 通过，25.85 秒 | 同上 |
| 完整任务，第 3 次 | 通过，25.83 秒 | 同上 |
| 暂停 → 返回 → 继续 | 通过 | 第 1 株浇水后暂停；恢复后总共只有 12 个不同地块的浇水动作，无重复 |
| 执行中出现真实动态障碍 | 通过 | bot-2 正常走到 `[46,18]` 挡路；bot-1 发生 1 次重规划，绕行到 `[49,18]` |
| 不可达目标负例 | 符合预期 | 对实际地图中的不可通行格 `[54,7]` 返回 `failed/unreachable`；未错误报告成功 |

另有阶段 0 的真实移动、浇水效果、收获入包、取消到安全边界、同 ID 重试不重复执行、旧会话拒绝六项检查全部通过。算法/任务层六个单元测试通过。

这是小型受控场景的验证，不能外推成“任何农场任务成功率 100%”。单轮约 26 秒是这张固定测试地块的真实耗时，不包含高层 LLM 推理延迟。

## 可复现证据

- `python3 evals/stage0_smoke.py` → `outputs/stage0-evidence.json`
- `python3 evals/stage1_tasks.py` → `outputs/stage1-report.json`
- `python3 evals/dynamic_obstacle.py` → `outputs/dynamic-obstacle-report.json`
- SQLite 动作与任务记录：`work/tasks.sqlite`

原始动作记录体积较大，默认不入 Git。测试脚本与本报告随阶段提交，任何人可在同版本游戏环境中重跑。执行测试会重置专用 AgentLab 场景。

## 已知限制

只控制当前地图；只开放普通手摘作物；收获掉落需由本机器人拾取，其他实体抢走时不会误判自己收到。单步取消允许已开始动作正常完成，取消不回滚游戏效果。尚未实现多人联机、统一双机器人调度、跨地图任务或箱子归仓。

本次开发启动没有运行 Steam 客户端，游戏提示 Steam 成就不可用；未发现本项目 Mod 的运行异常。
