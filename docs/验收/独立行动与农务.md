# 独立行动与农务验收（2026-09-19）

环境：macOS、Stardew Valley 1.6.15、SMAPI 4.5.2、固定版本 Squad。仅操作 AgentLab 测试存档。

已实机验证：

- 指定 Abigail 挖矿，即使 Leah 更靠近目标也不会冒领结果；幂等回执、重复 ID 冲突、过期目标、取消保持原有检查通过。
- 两次浇水与两次收获由实际游戏状态变化确认。
- 玩家离开 Farm 到 BusStop 后，Abigail 留在 Farm，从 (43,19) 走到 (46,24)，真实浇灌 (46,25)。完成耗时约 2.02 秒；不是直接修改完成标志。
- 主动 travel 从 Farm (43,18) 沿地图出口到达 BusStop (11,23)，约 7.68 秒；玩家仍在 Farm。
- 农场动物抚摸与机器产物收取的新增测试通过。动物移动会终止旧目标并重新获取，不冒领其他动物的状态变化。
- Beach 钓鱼从 (23,31) 走到 (24,31)，实际保持约 10 秒后结束；本次收获 0 件，结果如实记录。
- 浇水、挖矿增加约 180ms 动作前摇；效果在前摇后发生，保留后续动作冷却。尚需录像评估整体自然程度。

修复：

- 自主管理角色不再因玩家走远自动中断工作；不在任意位置传送追赶。
- 跨地图仅沿现有 warp 出口走到边界再切换场景；没有可用边的门、楼梯与交通工具不会假装支持。
- 尊重 pauseWhenOutOfFocus，动作计时和实际更新采用相同暂停条件。
- 出发格本身被占用或不可通行时，允许走出该格；仍阻止走入新的不可通行格。
- 构建与启动对隔离运行目录互斥；DLL 原子替换，防止覆盖正在映射的程序文件。

复现：关闭隔离游戏后执行 `python3 scripts/build_companion.py`，再用 `python3 scripts/launch.py --lab --companion`，加载 AgentLab 并关闭面板。农场执行 `evals/companion_control.py`、`evals/together_control.py`、`evals/farm_care.py`。开发夹具会重建专用区域，不适用于个人存档。

仍有限制：dismiss 仍使用上游回家逻辑；未声明所有地图、门、矿洞楼梯或多人模式均可用；收机器目前进入玩家背包；箱子搬运、补料和播种未接入。本阶段不代表完整设计已完成。
